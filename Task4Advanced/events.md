# Каталог доменных событий — «Будущее 2.0»

## Общий конверт события (envelope)

Каждое событие несёт стандартные метаданные плюс полезную нагрузку:

```json
{
  "eventId": "uuid",
  "eventType": "clinic.patient.registered",
  "occurredAt": "ISO-8601",
  "version": "1.0",
  "producer": "clinics-context",
  "partitionKey": "partyId",
  "payload": { }
}
```

Правила контракта:
- **Прошедшее время** в названии — событие это свершившийся факт.
- **Версионирование** (`version`) и регистрация схемы в Schema Registry; изменения только обратносовместимые.
- **Без чувствительных данных в payload.** Медкарты, истории болезней, результаты исследований и платёжные реквизиты **не передаются** — только идентификаторы и ссылки (`resultRef`, `accountId`). Подписчик при необходимости и при наличии прав запрашивает детали у владельца.
- **Идемпотентность** по `eventId`; `partitionKey` обеспечивает порядок в рамках сущности.

## Каталог

### Зарегистрирован пациент
- **Тип:** `clinic.patient.registered`
- **Источник:** Клиники
- **Семантика:** в сети клиник заведён новый пациент.
- **Подписчики:** Биллинг, ИИ-диагностика, Витрина
- **Контракт:** `{ patientId, partyId, clinicId, occurredAt }`

### Завершён приём
- **Тип:** `clinic.encounter.completed`
- **Источник:** Клиники
- **Семантика:** приём проведён, услуги зафиксированы.
- **Подписчики:** Биллинг, Витрина
- **Контракт:** `{ encounterId, patientId, serviceCodes[], completedAt }`

### Пройдено исследование ИИ
- **Тип:** `ai.study.completed`
- **Источник:** ИИ-диагностика
- **Семантика:** ИИ-анализ завершён, результат готов.
- **Подписчики:** Клиники (врач), Витрина
- **Контракт:** `{ studyId, patientId, modelId, status, resultRef, completedAt }`

### Открыт счёт
- **Тип:** `bank.account.opened`
- **Источник:** Счета и платежи
- **Семантика:** клиенту открыт банковский счёт.
- **Подписчики:** Комплаенс, Витрина
- **Контракт:** `{ accountId, partyId, currency, openedAt }`

### Проведён платёж
- **Тип:** `bank.payment.posted`
- **Источник:** Счета и платежи
- **Семантика:** платёж успешно проведён по счёту.
- **Подписчики:** Биллинг, Витрина
- **Контракт:** `{ paymentId, accountId, amount, currency, postedAt }`

### Создан кредитный договор
- **Тип:** `lending.agreement.created`
- **Источник:** Кредитование
- **Семантика:** оформлен кредитный договор на основе одобренной заявки.
- **Подписчики:** Счета, Комплаенс, Уведомления, Витрина
- **Контракт:** `{ agreementId, partyId, principal, currency, rate, termMonths, createdAt }`

### Выдан кредит
- **Тип:** `lending.credit.disbursed`
- **Источник:** Кредитование
- **Семантика:** средства по договору зачислены на счёт.
- **Подписчики:** Счета, Витрина
- **Контракт:** `{ agreementId, accountId, amount, disbursedAt }`

### Дано согласие на обработку
- **Тип:** `party.consent.granted`
- **Источник:** Клиенты и согласия
- **Семантика:** субъект дал согласие на обработку данных (в т.ч. для ИИ-анализа).
- **Подписчики:** ИИ-диагностика, Клиники
- **Контракт:** `{ partyId, scope, grantedAt, expiresAt }`
