# Агрегаты — «Будущее 2.0»

Для каждого ключевого агрегата: контекст, корень, ключ (идентичность), инварианты (правила, истинные на границе агрегата) и публикуемые события. Правило DDD: транзакция не выходит за границу одного агрегата; согласованность между агрегатами — через события (eventual consistency).

## Пациент
- **Контекст:** Клиники
- **Корень:** `Patient`
- **Ключ:** `patientId` (UUID); ссылается на `partyId` (shared kernel)
- **Инварианты:** один `Patient` на один `partyId` в рамках сети клиник; медкарта, истории болезней и результаты исследований принадлежат агрегату и **не покидают контекст** в аналитику; статус активности.
- **События:** Зарегистрирован пациент, Обновлены данные пациента

## Приём (Encounter)
- **Контекст:** Клиники
- **Корень:** `Encounter`
- **Ключ:** `encounterId`
- **Инварианты:** принадлежит ровно одному `patientId`; жизненный цикл `scheduled → completed → cancelled` без обратных переходов; набор оказанных услуг фиксируется при завершении.
- **События:** Запланирован приём, Завершён приём

## Исследование (AI Study)
- **Контекст:** ИИ-диагностика
- **Корень:** `Study`
- **Ключ:** `studyId`
- **Инварианты:** запуск возможен только при действующем согласии (`ConsentGranted`); ссылается на входные данные и `modelId`; результат неизменяем после финализации; наружу отдаётся ссылка на результат, а не сами медданные.
- **События:** Запрошен ИИ-анализ, Пройдено исследование ИИ

## Счёт (Account)
- **Контекст:** Счета и платежи
- **Корень:** `Account`
- **Ключ:** `accountId`
- **Инварианты:** баланс не ниже разрешённого овердрафта; валюта неизменна после открытия; принадлежит одному `partyId`; статус `active → frozen → closed`.
- **События:** Открыт счёт, Закрыт счёт

## Платёж (Payment)
- **Контекст:** Счета и платежи
- **Корень:** `Payment`
- **Ключ:** `paymentId`; идемпотентность по `externalRef`
- **Инварианты:** дебет и кредит сбалансированы; повторная обработка одного `externalRef` не создаёт дубля; статус `pending → posted | failed`.
- **События:** Инициирован платёж, Проведён платёж, Платёж отклонён

## Кредитный договор (Credit Agreement)
- **Контекст:** Кредитование
- **Корень:** `CreditAgreement` (включает график платежей)
- **Ключ:** `agreementId`
- **Инварианты:** тело кредита > 0; сумма платежей по графику равна телу плюс проценты; создаётся только из одобренной заявки; статус `draft → active → closed | default`.
- **События:** Создан кредитный договор, Выдан кредит, Кредит закрыт

## Party (клиент/субъект)
- **Контекст:** Клиенты и согласия
- **Корень:** `Party`
- **Ключ:** `partyId` (используется как shared kernel другими контекстами)
- **Инварианты:** один `Party` на одного реального субъекта; согласия хранятся со scope и сроком действия; отзыв согласия немедленно отражается в событиях.
- **События:** Создан Party, Дано согласие на обработку, Отозвано согласие
